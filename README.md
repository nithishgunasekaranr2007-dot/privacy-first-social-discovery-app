# privacy-first-social-discovery-app
 A privacy-focused location-based social networking application.
 Privacy-First Social Discovery App

A mobile social discovery application inspired by location-based social platforms.

Features

- User registration and login
- User profiles
- Nearby-user discovery using approximate location
- Private messaging
- Block and report users
- Privacy-focused location controls

Technologies

- Python
- Django REST Framework
- React Native
- PostgreSQL
